Reserve Court SF

Python · Selenium · REST API · multithreading · AWS EC2

SF's public tennis courts sell out 5–10 seconds after booking opens. I reverse-engineered the booking site's undocumented API and built a bot that reserves a court in ~1.5 seconds.

Fair play I only booked courts I was actually going to play on. No extras, never resold. Public courts should stay public.
Every morning, via cron on AWS EC2
  1. 07:58:00 Selenium logs in, grabs the auth token from cookies
  2. 07:59:00 Requests the SMS code early, reads it via TextVerified API
  3. 08:00:00 Hits every court's reservation endpoint in parallel (multithreading)
  4. 08:00:01 ✓ Court reserved in ~1.5s
100+courts booked in 3 months
~1.5saverage booking time
5–6ssaved by calling the API instead of clicking the UI
